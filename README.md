# E-Learn Platform

> **Note**: This was my **1st ever hackathon project**, built over 2 years ago! It holds a special place in my learning journey. It has recently been updated with a dark-mode glassmorphism UI.

The platform was originally designed to help disabled persons learn and grow through interactive features, accessibility tools (speech-to-text, text-to-speech, interactive quizzes), and curated resources.

## Features
- **Modern UI**: Full glassmorphism design with animated background orbs and sleek dark mode.
- **Fixed Login**: Bypass the database quickly with hardcoded credentials `admin@elearn.com` / `admin`.
- **Accessible Tools**: Customer support, interactive quizzes, dictation (speech-to-text), reader (text-to-speech), and image analysis.

## Getting Started

1. Clone the repository.
2. Ensure you have Node.js installed.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the server:
   ```bash
   node server.js
   ```
5. Navigate to `http://localhost:3002`.

*MySQL is configured but not strictly required to preview the application, thanks to the fixed login bypass.*
